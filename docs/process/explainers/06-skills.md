# Skills

**Qué es.** Paquetes de instrucciones reutilizables que Claude Code carga cuando la tarea encaja con su descripción; capturan un procedimiento del proyecto para no reexplicarlo en cada sesión.

**Cómo lo aplicamos aquí.** Creada para el harness: [`gift-novel-run`](../../../.claude/skills/gift-novel-run/SKILL.md) (validar brief, generar, vigilar checkpoints, leer validadores en SQLite, revisar la traza, abrir el lector con Playwright MCP, exportar PDF). Usadas durante el desarrollo: `react`, `sqlite`, `verification` y la de FastAPI instalada desde el wheel fijado. Procedencia y licencias en [`.claude/skills/README.md`](../../../.claude/skills/README.md); uso en [subagentes, comandos y skills](../subagentes-comandos-skills.md).
